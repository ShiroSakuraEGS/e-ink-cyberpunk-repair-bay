# Cyberpunk Repair Bay ⚡ 3D 霓虹裝置維修模擬器

> 踏入 2077 年的暗黑科技維修廠，扮演專屬硬體修理工程師，親手檢視、拆解、掃描並修復搭載尖端電子紙（E Ink）與微控制器架構的故障機械！

---

## 🎮 遊戲特色

- **純粹 CSS 3D 擬真渲染技術**：完全採用原生 HTML5、CSS 3D Transform 與 JavaScript 開發，無任何第三方龐大 3D 引擎依賴，極速輕量化。
- **WASD 自由視角攝影機**：支援 `W / A / S / D` 全向移動鏡頭，結合滑鼠拖曳旋轉與滾輪縮放，360 度無死角檢視裝置細節。
- **動態爆炸拆解（Explode View）**：真實呈現外殼立體厚度與各階層內部元件，一鍵滑桿自由控制爆炸距離，各零件獨立分離浮空展示。
- **元太科技 E Ink 深度硬體知識庫**：
  - 微膠囊與雙穩態電泳顯示核心
  - 電源管理晶片（PMIC）、Tcon 時序控制器
  - 柔性排線（FPC）、微裂紋金屬導線排查
- **即時診斷與修復工作台**：
  - **診斷掃描**：熱感應光譜透視、微結構裂紋偵測、電容脈衝訊號分析。
  - **維修工具**：精密雷射焊接儀、奈米導電凝膠筆、超音波精密清潔儀。
- **聲光氛圍與賽博龐克 HUD**：深色科技玻璃擬態（Glassmorphism）、脈衝掃描線、動態音效合成與微互動動畫。

---

## 🕹️ 操作指引

| 操作動作 | 控制方式 |
| :--- | :--- |
| **鏡頭平移 (Pan)** | 鍵盤 `W`（上）、`S`（下）、`A`（左）、`D`（右） |
| **視角旋轉 (Orbit)** | 滑鼠左鍵按住拖曳視角 |
| **鏡頭縮放 (Zoom)** | 滑鼠滾輪滾動（或使用右上方縮放按鈕） |
| **裝置拆解** | 拖曳「爆炸半徑」滑桿或點擊快速預設按鈕 |
| **零件檢視** | 點擊任意 3D 懸浮零件即可開啟診斷與修復控制面板 |

## 🚀 本地快速開始

本專案無需任何安裝流程或 Node.js 建置步驟：

2. 雙擊直接以現代瀏覽器（Chrome、Edge、Firefox、Brave 等）開啟 `index.html`。

## 🛠️ 技術架構

- **HTML5**：語意化結構、科技感介面 HUD、無障礙按鈕設計。
- **Vanilla CSS (CSS 3D)**：`transform-style: preserve-3d`、動態光影效果、響應式面板。
- **Vanilla JavaScript (ES6+)**：
  - 自訂 3D 攝影機矩陣與視角變換狀態機
  - 3D 立體六面體零件建構器（Cuboid Geometry Generator）
  - Web Audio API 賽博龐克合成音效引擎
  - 元件維修進度與診斷邏輯系統
